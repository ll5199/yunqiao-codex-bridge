一个轻量入口，连接你的模型与 Codex。

保留官方客户端熟悉的工作方式，只把账号、模型选择和中转连接集中到云桥。

登录后自动读取有效订阅、上游分组和对应模型，无需手动复制多组 Key。

常见问题

下载与使用说明

云桥会修改官方 Codex 客户端吗？

不会。云桥只使用 Codex 支持的自定义模型供应商配置，并通过本机代理连接 API，不修改官方安装文件。

为什么 Windows 可能提示“未知发布者”？

当前便携版尚未配置商业代码签名证书，请只从本页面或 GitHub 下载。

如何改回 ChatGPT 官方账号登录？

先结束当前工作并退出 Codex，再打开云桥，选择顶部“官方账号”，点击同一个“启动 Codex”按钮；随后在 Codex 中登录。

准备好连接你的 Codex 了吗？

下载 Windows 客户端，使用云桥账号、外部 API 或 ChatGPT 官方账号开始工作。
