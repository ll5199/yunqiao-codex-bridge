外部 API 快速开始

填写、保存、启动。

以下按新版单页界面说明。保存与同步已合并，智能模型默认选中。

01

选择外部 API，填写连接信息

打开云桥，在“连接类型”中选择外部 API。接口地址填写 https://api.velyn65.com/v1，API Key 填写你在服务后台创建的 Key。

使用其他兼容服务时，请填写该服务提供的 HTTPS 接口地址。云桥账号的登录密码不能当作 API Key。
02

保存 Key，模型自动同步

点击 保存并同步模型。成功后，Key 会加密保存在本机，模型列表自动更新，默认选中智能模型。不需要再找“获取模型”按钮。

Key 输入框显示“已加密保存，留空继续使用”是正常状态；之后无需每次重新填写。需要指定模型时，直接点击模型按钮，“查看更多”可展开列表。
03

启动 Codex，并保持云桥运行

点击唯一的 启动 Codex 按钮。启动过程中和 Codex 运行期间，按钮会变灰，显示“正在启动…”或“Codex 已启动”，不能重复点击。Codex 打开后，先发送一个简短任务确认模型能够回答。

使用外部 API 时请保持云桥运行，关闭云桥会停止本机代理。Codex 完全退出后，启动按钮会自动恢复。

另外两种连接方式

按你的账号选择入口。

顶部切换连接类型，底部仍然只有一个“启动 Codex”按钮。

云桥账号

  1. 选择顶部的云桥账号。
  2. 输入云桥账号和密码，点击登录并同步模型。
  3. 若账号有多个上游，直接点击对应上游按钮，查看同步后的模型列表。
  4. 选择智能模型或指定模型，然后点击启动 Codex。

官方账号

  1. 选择顶部的官方账号。
  2. 点击同一个启动 Codex按钮。
  3. 在官方 Codex 中使用自己的 ChatGPT 账号登录和工作。

新版没有单独的“原生账号启动”按钮，它已合并为“官方账号”连接方式。

切换配置：Codex 运行时修改连接或模型，会在下次启动时生效。请先结束当前工作并完全退出 Codex，再回到云桥确认新配置并启动。
更新与诊断

右上角设置，就能找到。

版本更新和排障入口集中在同一处。

检查更新

点击右上角设置图标，再点击检查更新。有新版时按提示下载、安装并重启；更新完成后可再次查看版本号。

导出诊断

遇到启动、代理或更新错误时，点击导出诊断，选择保存位置。客户端会隐藏已识别的凭据信息；请在发送前确认日志不含你不希望分享的内容。

错误反馈请附：云桥版本、Codex 版本、所选连接方式、完整错误提示和诊断日志。不要发送 API Key 或账号密码。
使用帮助

遇到问题，先看这里。

启动按钮变灰，无法再点

Codex 启动中或正在运行时，这是正常保护。先在 Codex 中结束工作并完全退出，等待云桥检测到退出后再启动；不要连续打开多个实例。

保存后没有模型或提示 Key 错误

核对 HTTPS 接口地址是否包含服务要求的 /v1 路径，并确认 Key 有效、有可用额度及模型权限；修改后再次点击“保存并同步模型”。

云桥账号登录后没有模型

确认订阅有效，选择你有权限的上游按钮。更换上游后会同步对应模型；仍为空时检查账号套餐，再退出并重新登录。

Codex 已打开，但提示调试连接或汉化未就绪

不要立即关闭云桥。本机代理可能仍在运行；先发送简短任务检查能否回答。到右上角设置中检查更新并“导出诊断”，提供日志及完整错误提示。

出现 overloaded 或 Concurrency limit exceeded

表示上游过载或并发已满。停止重复发送，稍后只保留一个任务重试。若已有部分输出或文件操作，先确认执行结果，再手动继续，避免重做整项任务。

为什么接口已保存，却仍然不能回答？

“配置已就绪”只说明已有连接配置，不代表上游请求一定成功。查看状态栏的代理和上游错误提示；保持云桥运行，并检查 Key 额度、网络及上游服务状态。
